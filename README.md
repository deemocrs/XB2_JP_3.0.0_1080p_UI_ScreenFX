# Xenoblade Chronicles 2 · 1080p Scene, UI and Screen Effects Fixes

[简体中文](README.zh-CN.md)

This mod targets version 3.0.0 of the Japanese/Chinese edition of Xenoblade Chronicles 2. It raises the base scene resolution from 1280×720 to 1920×1080 and fixes two issues that can appear at the higher resolution: a misplaced portrait for the selected Blade in battle and translucent rectangles in some cutscene effects.

## Patch contents

| Component | What it changes |
| --- | --- |
| **1080p Scene** | Changes two instructions to initialize the scene at 1920×1080. |
| **UIBounds** | Changes four instructions so UI bounds use the engine's logical width and height. Frame captures showed incorrect translation values for both the selected Blade portrait and its border. |
| **ScreenFX** | Changes four instructions to project the affected screen-space particles using their original 1280×720 coordinate system. Projecting those particles against 1920×1080 exposed the edges of effects meant to cover the screen. The effects still draw at the render target's actual resolution. |

## Installation

- Base game Title ID `0100F3400332C000`
- Build ID `FEEE7AFA8A1541BD67AED1A0061FBB57`

1. Stop the game. Download and extract the repository using **Code → Download ZIP**.
2. In Ryujinx, right-click the game and open its mod directory. Copy the `XB2_JP_3.0.0_1080p_UI_ScreenFX` subfolder from inside the extracted repository into that directory.
3. Enable the mod and restart the game. The log should show `Matching IPSwitch patch` with the patch filename.

## Resolution and testing

The UIBounds and ScreenFX fixes run independently of the 1080p scene initialization. If you set a different base scene resolution, you can retain both groups of fix instructions. Offline ARM64 tests covered 720p, 1080p, 1440p and 4K for both fixes, plus 1600×900 for ScreenFX. All tested resolutions were 16:9. A GPU replay of a 1080p capture showed that the rectangle edges disappeared.

The combined patch has been recorded loading in Ryujinx. Other emulators, ultrawide resolutions, changes to the logical UI canvas, and broader scene coverage still need in-game testing.
