# 异度之刃 2 · 1080p 场景与 UI／ScreenFX 修复

[English](README.md)

本 Mod 适用于《异度之刃 2》日／中版 3.0.0。它将场景基准分辨率从 1280×720 提高到 1920×1080，并修复提高分辨率后出现的选中异刃头像错位和部分过场特效的半透明矩形。

## 补丁内容

| 部分 | 改动 |
| --- | --- |
| **1080p Scene** | 修改 2 条指令，将场景初始化尺寸设为 1920×1080。 |
| **UIBounds** | 修改 4 条指令，让 UI 边界计算读取引擎提供的逻辑宽高。抓帧中，错位来自选中头像和边框的平移常量偏差。 |
| **ScreenFX** | 修改 4 条指令，让对应的屏幕空间粒子按 1280×720 逻辑坐标投影。粒子坐标沿用原版基准，用 1080p 尺寸投影会使原本应铺满画面的特效露出矩形边缘。修复后仍以实际渲染目标尺寸绘制。 |
